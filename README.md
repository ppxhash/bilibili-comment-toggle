# B站评论区开关 · 自写版（Edge 扩展）

> 一个面向 **Microsoft Edge** 的轻量浏览器扩展，一键隐藏 / 显示 B 站视频页评论区。
> 基于 Chromium Manifest V3 开发，纯本地运行，不申请任何网络权限，无任何数据上报。
> （同为 Chromium 内核的 Chrome 也可直接加载使用。）

## ✨ 主要特点

- **专注 Edge 体验**：为 Microsoft Edge 优化，通过 `edge://extensions` 开发者模式一键加载，无需商店审核。
- **悬浮胶囊按钮**：视频页右下角出现可拖动的胶囊按钮，左键点击即切换评论区「显示 / 隐藏」。
- **快捷键切换**：默认 `Alt + C` 快速开关评论区，手不离键盘。
- **UP 白名单**：右键胶囊按钮打开面板，可一键把当前 UP 加入白名单，或粘贴 `space.bilibili.com/<mid>` 主页链接手动添加；白名单 UP 的视频默认**显示**评论区。
- **多标签页同步**：基于 `chrome.storage`，开关状态与白名单会自动同步到同浏览器其他标签页。
- **状态一目了然**：扩展图标带 `ON / OFF` 徽章（粉色=已隐藏，灰色=已显示）；白名单 UP 时胶囊按钮带绿色描边。
- **姿态友好**：默认隐藏评论区；按钮位置可拖动并记住，刷新 / 换页后保持。
- **隐私优先**：无网络请求、无 `eval` / `innerHTML`、不读取 Cookie，仅写入自己的 4 个本地存储键。

## 📦 安装（Microsoft Edge）

1. 克隆或下载本仓库：
   ```bash
   git clone https://github.com/ppxhash/bilibili-comment-toggle.git
   ```
2. 打开 Edge，地址栏输入并回车：
   ```
   edge://extensions
   ```
3. 右上角打开 **「开发者模式」**（Developer mode）开关。
4. 点击 **「加载解压缩的扩展程序」**（Load unpacked），选择本仓库文件夹。
5. 扩展出现在列表即安装完成；视频页右下角会出现胶囊按钮。

> Chrome 用户同理：打开 `chrome://extensions` → 开启开发者模式 → 加载解压缩的扩展程序。

## 🚀 使用方式

- 进入 B 站任意 **视频 / 番剧 / 列表页**，右下角出现胶囊按钮。
- **左键点击按钮** 或按 **`Alt + C`** → 切换评论区显示 / 隐藏。
- **右键点击按钮** → 打开 UP 白名单面板（加入 / 移出 / 手动添加 / 删除）。
- 按钮可**拖动**到任意位置，位置会被记住。
- 想恢复评论区，再次左键点击按钮或按快捷键即可。
- 若快捷键不生效，可在 `edge://extensions/shortcuts` 中查看 / 重新指派 `Alt + C`。

## 🎯 UP 白名单

- **右键**胶囊按钮打开面板：显示当前视频 UP 的昵称与 mid，一键「加入 / 移出」。
- 面板输入框支持**手动添加**，接受两种格式（可用逗号 / 空格分隔批量）：
  - UP 主页链接：`https://space.bilibili.com/486906719/?spm_id_from=...`
  - 纯数字 mid：`486906719`
- 名单条目可逐个 `×` 删除，列表按添加时间倒序。
- 白名单以 **mid（数字 ID）**为准，UP 改名不会失效；界面上显示昵称方便辨认。
- 命中白名单时胶囊按钮带**绿色描边**，该 UP 的视频默认显示评论区（仍可左键 / `Alt + C` 手动隐藏）。

### 已知边界

- **手动切换只对当前视频有效**：切换或刷新视频后回到默认规则（白名单 UP 显示，其余隐藏）。
- **番剧页没有 UP 概念**，白名单不适用，按默认隐藏处理。
- **联合投稿**只识别主 UP，`owner` 之外的合作 UP 不在页面 DOM 里，无法匹配。
- 未申请网络权限，因此**无法用昵称搜索 UP**，只能粘贴主页链接或填写 mid。
- UP 识别依赖页面 DOM 结构，B 站大改版可能导致识别失败；失败时自动降级为默认隐藏。

## 🧩 文件结构

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | 扩展配置（Manifest V3，仅申请 `storage` 权限） |
| `background.js` | 后台服务 worker：转发工具栏图标点击 / `Alt + C` 快捷键，更新徽章 |
| `content.js` | 注入页面脚本：悬浮按钮、隐藏 / 显示逻辑、UP 识别与白名单面板、多标签同步 |

## 🔒 隐私说明

本扩展**不发起任何网络请求**，不收集、不上报任何数据。所有状态仅保存在你本机的浏览器存储中（共 4 个键：`hidden`、`pos`、`whitelist`、`upCache`）。UP 主识别走纯 DOM 解析，不调用任何 B 站接口。代码无第三方依赖、无远程脚本。
